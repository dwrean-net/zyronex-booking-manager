# ZyroNex Booking Manager

Το **ZyroNex Booking Manager** είναι μια δωρεάν εφαρμογή διαχείρισης κρατήσεων και ακινήτων που λειτουργεί απευθείας μέσα από τον browser, χωρίς εγκατάσταση.

## Τι προσφέρει

Η εφαρμογή συγκεντρώνει σε ένα ενιαίο περιβάλλον λειτουργίες για:

- διαχείριση κρατήσεων βραχυχρόνιας μίσθωσης
- Booking.com, Airbnb, Vrbo και Expedia
- ακίνητα και επισκέπτες
- ημερολόγιο και ειδοποιήσεις
- έξοδα και βασικά οικονομικά στοιχεία
- ΤΑΚΚ και ΕΟΤ
- ζημιές και αποζημιώσεις
- στατιστικά και αναλύσεις
- μακροχρόνιες μισθώσεις
- οχήματα και πρόσθετες υπηρεσίες
- δημιουργία και επαναφορά αντιγράφων ασφαλείας

Η εφαρμογή μπορεί να λειτουργήσει και χωρίς σύνδεση στο Internet, καθώς τα δεδομένα αποθηκεύονται τοπικά στον browser. Υποστηρίζεται επίσης προαιρετικός συγχρονισμός μέσω Supabase.

## Χρήση

1. Κατέβασε το αρχείο `ZyroNex_Booking_Manager.html`.
2. Αποθήκευσέ το σε έναν σταθερό φάκελο και μην αλλάζεις θέση ή όνομα αφού αρχίσεις να καταχωρείς δεδομένα.
3. Άνοιξέ το με Chrome, Edge, Firefox ή Safari.
4. Πριν από σημαντικές αλλαγές ή ενημερώσεις, κράτησε αντίγραφο ασφαλείας μέσα από την εφαρμογή.

Για αναλυτικές οδηγίες, κατέβασε και τον πλήρη οδηγό χρήσης PDF που περιλαμβάνεται στο repository.

## Σημαντική σημείωση

Οι φορολογικοί και οικονομικοί υπολογισμοί της εφαρμογής έχουν ενημερωτικό χαρακτήρα και δεν αντικαθιστούν λογιστή ή επίσημη φορολογική συμβουλή. Η εφαρμογή δεν εκδίδει παραστατικά και δεν αποστέλλει στοιχεία στην ΑΑΔΕ.
