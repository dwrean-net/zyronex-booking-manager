# ZyroNex Booking Manager

**Δωρεάν εφαρμογή διαχείρισης κρατήσεων και ακινήτων, χωρίς εγκατάσταση.**

Το **ZyroNex Booking Manager** δημιουργήθηκε από τον **Θανάση Λεβαντή — ZyroNex** και λειτουργεί απευθείας μέσα από τον browser ως ένα αυτοτελές αρχείο HTML.

**Ημερομηνία έκδοσης:** 05/08/2026

## Τι προσφέρει

Η εφαρμογή συγκεντρώνει σε ένα ενιαίο περιβάλλον λειτουργίες για:

- διαχείριση κρατήσεων βραχυχρόνιας μίσθωσης
- Booking.com, Airbnb, Vrbo και Expedia
- ακίνητα και επισκέπτες
- ημερολόγιο και ειδοποιήσεις
- έξοδα και βασικά οικονομικά στοιχεία
- ΤΑΚΚ και ΕΟΤ
- ζημιές και αποζημιώσεις
- στατιστικά και αναλύσεις
- μακροχρόνιες μισθώσεις
- οχήματα και πρόσθετες υπηρεσίες
- δημιουργία και επαναφορά αντιγράφων ασφαλείας

Η εφαρμογή μπορεί να λειτουργήσει και χωρίς σύνδεση στο Internet, καθώς τα δεδομένα αποθηκεύονται τοπικά στον browser. Υποστηρίζεται επίσης προαιρετικός συγχρονισμός μέσω Supabase.

## Πώς χρησιμοποιείται

1. Κατέβασε το `ZyroNex_Booking_Manager.html`.
2. Τοποθέτησέ το σε έναν σταθερό φάκελο πριν αρχίσεις να καταχωρείς δεδομένα.
3. Άνοιξέ το με Chrome, Edge, Firefox ή Safari.
4. Χρησιμοποίησε τον αναλυτικό PDF οδηγό για την αρχική ρύθμιση και τις επιμέρους λειτουργίες.
5. Κράτα τακτικά αντίγραφα ασφαλείας μέσα από την εφαρμογή.

> **Προσοχή:** Μην αλλάζεις τη θέση ή το όνομα του αρχείου αφού αρχίσεις να καταχωρείς δεδομένα, χωρίς προηγουμένως να έχεις κρατήσει αντίγραφο ασφαλείας.

## Συμβατότητα

Επειδή πρόκειται για αυτοτελές αρχείο HTML, μπορεί να χρησιμοποιηθεί σε **Windows, macOS και Linux** με σύγχρονο browser. Ο επίσημος οδηγός περιλαμβάνει επίσης οδηγίες για χρήση από κινητές συσκευές.
